Dark · Creature Tiles. The board is a dark teal game-mat. The top 3 sit on a stepped podium of creature cards — #1 largest and gold, #2 and #3 progressively smaller — then everyone else is a full-width creature-card tile below. Each tile carries the full stat line: rank badge, creature avatar, name, chips for games / win% / streak (green win-streak, red loss-streak, "–" for none), and the big rating with its label (or "UNRATED" for a player with no games yet, like Rick #8).
