# 1v1 Format Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add 1v1 as a first-class format (loggable, own rating track, filterable, shown on player detail), with full parity to 2v2/3v3; 1v1 also feeds the Total track and never appears in the Teams view.

**Architecture:** Widen `Format`/`Track`, add a `1v1` track to the engine (no math change), migrate the `format` enum, guard teams against 1-player lineups, and thread `1v1` through the log form, board filter, and player detail page.

**Tech Stack:** SvelteKit 2, Svelte 5, TypeScript, Drizzle + Postgres (Neon), Vitest.

## Global Constraints

- `Format = '1v1' | '2v2' | '3v3'`; `Track = 'total' | '1v1' | '2v2' | '3v3'`.
- Teams are strictly ≥2-player lineups; a 1v1 must never create a team.
- The `1v1` filter segment shows only in the Players view.
- `pnpm check` 0/0, `pnpm lint` clean, full vitest suite green.
- Commit under the repo-local identity; commit/push only when asked.

- [ ] **Step 4: Add the 1v1 track to the engine**

In `src/lib/rating/engine.ts`, extend `RatingResult` and `computeRatings`:

```ts
export interface RatingResult {
	total: TrackResult;
	'1v1': TrackResult;
	'2v2': TrackResult;
	'3v3': TrackResult;
}

export function computeRatings(
	games: GameInput[],
	config: RatingConfig = DEFAULT_CONFIG
): RatingResult {
	return {
		total: computeTrack(games, config),
		'1v1': computeTrack(
			games.filter((g) => g.format === '1v1'),
			config
		),
		'2v2': computeTrack(
			games.filter((g) => g.format === '2v2'),
			config
		),
		'3v3': computeTrack(
			games.filter((g) => g.format === '3v3'),
			config
		)
	};
}
```
